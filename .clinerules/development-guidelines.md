## Brief overview
This document outlines the development guidelines for working on the FDx SDK Pro for Java v1.12 project. It includes communication preferences, coding conventions, and workflow strategies to ensure consistency and efficiency.

## Communication style
- Use concise and direct responses when interacting with Cline.
- Avoid conversational fillers like "Great" or "Okay"; focus on technical clarity.
- Provide clear explanations for tool usage and decisions.

## Development workflow
- Break tasks into clear, actionable steps and track progress using a todo list.
- Use the task_progress parameter to maintain an updated checklist.
- Confirm the success of each step before proceeding to the next.

## Coding best practices
- Follow Java coding conventions, including proper indentation and naming standards.
- Use descriptive names for variables, methods, and classes.
- Write modular and reusable code to enhance maintainability.

## Testing strategies
- Test all implemented features thoroughly to ensure functionality.
- Use unit tests where applicable to validate code behavior.
- Address edge cases and potential error scenarios.

## Comment verbosity
- Write clear and concise comments to explain complex logic.
- Avoid over-commenting; focus on areas that require clarification.

## File organization
- Maintain a logical directory structure for easy navigation.
- Place new files in appropriate directories, adhering to the existing structure.

## Other guidelines
- Spend adequate time on planning and architecture before implementation.
- Use the tools provided effectively to accomplish tasks iteratively.
- Ensure all changes are compatible with the existing codebase and follow project standards.
